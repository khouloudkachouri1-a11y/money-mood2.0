Money Mood PWA - how to put it online (free, GitHub Pages)

1. Create a free account at github.com, then click New repository (name: money-mood, set to Public).
2. Click "uploading an existing file" and drag in ALL the files from this folder
   (index.html, manifest.webmanifest, sw.js and the 4 icon-*.png files). Commit.
3. Go to Settings > Pages. Under "Build and deployment", choose Deploy from a branch,
   pick the main branch and the / (root) folder, then Save.
4. After a minute your app is live at https://YOUR-USERNAME.github.io/money-mood/

Install it:
- iPhone (Safari): open the link > Share > Add to Home Screen.
- Android (Chrome): open the link > menu > Install app.
- Desktop (Chrome/Edge): click the install icon in the address bar.

Note: data is saved per address on each device, so the hosted app starts empty.
